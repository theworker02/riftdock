# riftdock

Rift color dock values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/riftdock/

## Install / run

```bash
git clone https://github.com/theworker02/riftdock.git
cd riftdock
node src/cli.js
node --test
```
