Rift color dock values and contrast-safe presentation helpers. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/riftdock.git
cd riftdock
node src/cli.js --help
node --test
